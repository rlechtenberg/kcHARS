# Write/overwrite file in the cache

Write/overwrite file in the cache

## Usage

``` r
write_to_cache(x, cache)
```

## Arguments

- x:

  the object to write/overwrite in the cache, using the file path
  generated by construct_cache_file_path()

- cache:

  One of "use", "ignore", "overwrite". If `cache` = 'use', `x` is saved
  to the cache so long as it doesn't already exist there. If `cache` =
  'overwrite', `x` is saved to the cache, overwriting an existing object
  if one exists. If `cache` = 'ignore', nothing is done.

## Value

Saves an .rds file to the cache depending

df <- data.frame(x = 1:10)
temp_fun <- function(x = 1, y = 2, z = 3, cache){product = x*y*z; write_to_cache(x = product, cache = cache)}

#> Error in write_to_cache(x = product, cache = cache): could not find function "write_to_cache"
temp_fun(cache = "overwrite")
