# Compile a list of documented dates of HIV care (labs and optionally care_nolab and/or ARV use)

Compile a list of documented dates of HIV care (labs and optionally
care_nolab and/or ARV use)

## Usage

``` r
get_care_dts(
  incl_care_nolab = TRUE,
  incl_ARV_dts = TRUE,
  excl_care_before_dx = TRUE,
  care_dt..to = "15",
  care_dt....to = "0630",
  cache = "use"
)
```

## Arguments

- incl_care_nolab:

  Logical value specifying whether to include care_nolab dates

- incl_ARV_dts:

  Logical value specifying whether to include documented dates of ARV
  use

- excl_care_before_dx:

  Logical value specifying whether to drop care dates earlier than the
  earliest date of HIV diagnosis

- care_dt..to:

  Two-digit (zero-padded, as needed) character value specifying the day
  to impute for dates of care, where missing. Defaults to '15'

- care_dt....to:

  Four-digit (zero-padded, as needed) character value specifying the
  month+day to impute for dates of care, where missing. Defaults to
  '0630'

- cache:

  Whether to use or overwrite cached results. Must be one of 'use' (the
  default), 'overwrite', or 'ignore'. If cache = 'use' (the default) and
  a dataset was generated by a previous call to this function *using the
  same parameters* and the same eHARS data and was cached, the cached
  dataset is returned, otherwise a dataset is derived and cached. If
  cache = 'overwrite', a dataset is (re-)derived and (re-)cached,
  overwriting any existing analogous dataset in the cache. If cache =
  'ignore', a dataset is re-derived but not (re-)cached.

## Value

A data.frame unique by stateno + care_dt_char (i.e., character value
stored in lab.sample_dt / care_nolab_dt from the observation dataset /
arv_prophylaxis.drug_start_dt / arv_prophylaxis.drug_last_use_dt).
Contains variables care_dt (Date), care_type (1+ of: 'VL', 'CD4 cnt',
'CD4 pct', 'care_nolab (doc)', 'care_nolab (self-rpt)', 'drug_start_dt',
'drug_last_use_dt'), first_enter_dt (Date; earliest enter_dt for any
document with this stateno + care_dt_char), document_uid (for documents
with this stateno + care_dt_char, by care_type), and facility (for *lab*
documents with this stateno + care_dt_char).

## Details

The cached dataset is stored in the "/Derived" subdirectory of the
date-specific folder containing the eHARS datasets. If no such directory
exists when this function is called, it creates it.

