# Derive an analysis-ready data set listing viral loads (VL)

Derive an analysis-ready data set listing viral loads (VL)

## Usage

``` r
get_VLs(missing_result = 199, cache = "use")
```

## Arguments

- missing_result:

  Numeric value (including NA_integer\_) to impute for the result
  when (1) the person's VL records for that date are *all* missing a
  value for result *and* (2) some have an interpretation of '\<' or 'ND'
  and none have an interpretation of '\>'.

- cache:

  Whether to use or overwrite cached results. Must be one of 'use' (the
  default), 'overwrite', or 'ignore'. If cache = 'use' (the default) and
  a dataset was generated by a previous call to this function *using the
  same parameters* and the same eHARS data and was cached, the cached
  dataset is returned, otherwise a dataset is derived and cached. If
  cache = 'overwrite', a dataset is (re-)derived and (re-)cached,
  overwriting any existing analogous dataset in the cache. If cache =
  'ignore', a dataset is re-derived but not (re-)cached.

## Value

A data.frame unique by stateno + sample_dt_char (i.e., the original
value in lab.sample_dt). Contains variables sample_dt (Date; .. imputed
as 15 and .... imputed as 0630), max_result_unimputed (num), result
(num; equals `missing_result` under the conditions specified above,
otherwise equals max_result_unimputed), result_interpretation (chr; 'I'
and '=' are omitted), first_enter_dt (Date; earliest enter_dt for any
document with a VL with this stateno + sample_dt), document_uid, and
facility (chr).

## Details

The cached dataset is stored in the "/Derived" subdirectory of the
date-specific folder containing the eHARS datasets. If no such directory
exists when this function is called, it creates it.

## Examples

``` r
vls <- get_VLs()
#> Error: '//kc/dph/prevention/hiv/Epi/EXTRA SPACE/eHARS/Full eHARS/Archive/NA/document_sas7bdat/lab.sas7bdat' does not exist.
```
